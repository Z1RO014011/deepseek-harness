# DSH League of Legends BP Coach

An early external plugin for DeepSeek Harness that stores five-player champion pools and records draft picks, bans, recommendations, and match completion in SQLite.

This M1 bundle provides structured BP tools. Screenshot capture, champion patch data, and live visual recognition are planned integrations and are not included yet.

Requires Node.js 24.9+ and a compatible DSH 0.2 prerelease. Install from a local checkout with:

```sh
dsh plugin --profile lol-coach add /path/to/deepseek-harness/plugins/lol-coach
```
